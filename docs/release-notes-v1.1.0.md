# AC6 Win/Loss Tracker v1.1.0

This release improves capture reliability, lifecycle safety, history usability, and optional milestone screenshots.

## Changes

- Improved AC6 capture with Windows Graphics Capture.
- Improved recognition continuity and recovery around Alt+Tab.
- Hardened Launcher lifecycle and duplicate-process prevention.
- Expanded Dashboard history to the latest 50 matches with scrolling.
- Added optional screenshots of milestone win-streak effects.
- Added a GUI setting for milestone screenshots.
- Effect screenshots can preserve the composition visible over the AC6 client, including user-visible SteamP2PScanner, NVIDIA, Steam, Discord, and similar overlays/windows.
- Improved diagnostics and bounded screenshot outcome logging.
- Preserved match history and configuration across update/reinstall/uninstall workflows.
- Hardened process ownership, child cleanup, runtime/port cleanup, and failure rollback paths.

Supported mode remains **RANK MATCH: SINGLE only**. CUSTOM MATCH and RANK MATCH: TEAM are not supported by this release.
